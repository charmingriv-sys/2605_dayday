# Phase 12 강사 근태 및 라이프사이클 관리 기능 릴리즈 노트

본 문서는 Phase 12A~12H 과정에서 구현 및 고도화된 강사 근태 및 라이프사이클(퇴사, 복직, 삭제 제한, 일정/원생/출결 연동) 관련 기능 범위와 정책, 운영 검수 체크리스트 및 잠재 리스크를 정리한 문서입니다.

---

## 1. 기능 범위 및 구현 요약 (Phase 12A~12H)

### 1) 강사 근태관리 (`teacherAttendanceView.js`)
* **일간/주간/월간 조회 및 필터**: 오늘, 이번주, 이번달 프리셋 선택 기능 및 기간 직접 입력 필터 연동.
* **KPI 카드**: 출근, 미출근, 퇴근 완료, 미퇴근 지표를 범위(일간/기간)에 맞게 요약 출력.
* **상태 필터링**: 전체 상태, 미출근, 출근, 퇴근 완료, 미퇴근 등 특정 상태 조건에 맞는 정밀 조회 기능.
* **강사 필터**: 퇴사자는 기본 목록에서 숨기되, 선택 범위 내에 근무 일정, 근태 로그, 혹은 수강생 배정 수업이 있는 퇴사 강사는 `(퇴사)` suffix를 붙여 안전하게 포함 노출.

### 2) 강사 근무 수동 추가 및 수정
* **근무 기록 추가**: 퇴사 강사를 배제한 재직 강사만을 대상으로 출근/퇴근 시각, 날짜, 수동 추가 메모를 기입하여 근태 로그를 신규 생성 (중복 일자 등록 방어 밸리데이션 포함).
* **근무 기록 수정**: 기존 출퇴근 시각의 분 단위 미세 조정, '퇴근 누락(미퇴근) 처리' 체크박스 기능, 수정 사유 입력 의무화 및 히스토리 이력(`db.teacherAttendanceEditLogs`) 보존.

### 3) 강사 상세 드로어 및 캘린더
* **월간 요약 정보**: 특정 강사의 선택 월 출근일수, 총 근무시간, 평균 근무시간, 미퇴근 횟수를 산출하여 표시.
* **달력(Calendar) 그리드**: 날짜별 출결 상태(`completed`, `missed`, `today-working`, `absent`)에 맞춘 배경색, 보더(오늘 표시), 요약 정보(근무시간/근무중/미출근) 시각화.
* **수정 이력 섹션**: 해당 강사의 근태 수정 기록 중 최근 5건의 변경 사항(수정자, 수정일시, 수정 전/후 시간 및 수정 사유)을 시간순 노출.

### 4) 엑셀 다운로드 (Excel XML Export)
* **다운로드 방식**: 브라우저 다운로드 스트림 연동을 통해 `.xls` (SpreadsheetML XML 템플릿 방식) 파일 내보내기.
* **시트 구조**: 
  - `월간 합산` 시트: 선택 범위 내에 출근 기록이 존재하는 강사들의 합계 정보 요약.
  - `강사별 개별` 시트: 강사별 일별 근무 현황(날짜, 요일, 출/퇴근시각, 근무시간, 상태, 기록방식, 메모) 개별 시트 자동 생성.
* **보안 및 정합성**: 시트명 특수문자 제거(Sanitize) 및 XML Escape 적용, 파일명 타임스탬프 결합, 빈 기록 강사 자동 제외 처리.

### 5) 강사 퇴사 및 복직 처리 (`staffView.js`)
* **퇴사 처리**: 퇴사일자(`resignedAt`)와 퇴사 사유(`resignMemo`)를 입력받아 퇴사 상태(`resigned`)로 전환. 퇴사된 강사는 배정용 UI에서 배제되며 목록 내 `퇴사` 배지가 부착됨.
* **복직 처리**: 기존의 고유 ID(`teacher.id`)를 유지하면서 `employmentStatus`를 `active`로 재전환. 퇴사일자 및 사유를 초기화하고 기존의 모든 연동 데이터(근태, 시간표 등)가 자동으로 활성 상태로 원복됨.

### 6) 삭제 제한 및 무결성 검증
* **삭제 불가 조건**: 근태 기록, 근무 일정, 담당 학생, 시간표 스냅샷, 수업 오버라이드 내역, 시간표 조작 로그, 학원 주요 일정 등 7개 연동 테이블의 이력이 1개라도 남아 있는 강사의 물리 삭제를 차단하고 '퇴사 처리하기'로 안내.
* **삭제 허용**: 가입 후 아무 이력이 없는 신규/오등록 강사에 한해서만 물리 삭제 기능 작동.

### 7) 연동 화면 필터/표시 정책
* **시간표/출근표 (`sessionsView.js`)**: 퇴사한 강사는 미래 주차 배정이나 필터 목록에서 제외되며, 과거 이력 조회를 위해 명시적인 `퇴사한 강사 포함` 토글이 켜진 경우에만 노출.
* **원생 관리 (`membersView.js`)**: 신규 원생 배정 시 퇴사 강사는 제외하되, 기존 배정 원생의 상세 페이지에서는 `[강사명] (퇴사)`로 정상 표시.
* **주요 일정 / 출결 관제**: 퇴사 강사가 담당했던 과거 일정/출결 데이터는 수정 없이 원본 보존.

## 2. 운영 검수 체크리스트

학원 원장/운영자 시점에서 서비스 오픈 전 화면별로 검증해야 할 체크리스트입니다.

### 1) 강사 관리 화면
- [ ] **퇴사/복직 알림 및 Confirm 문구**:
  - 강사 퇴사 시 Confirm 창 문구가 `"정말로 [강사명] 강사를 퇴사 처리하시겠습니까?\n퇴사 처리 후에는 새 배정 선택 목록에서 제외됩니다."`로 정확히 표시되는가?
  - 퇴사 완료 후 `"강사 퇴사 처리가 완료되었습니다."` Toast가 정상 노출되는가?
  - 퇴사 강사 상세 폼에서 '퇴사 취소' 클릭 시 `"이 강사를 복직(재직) 처리하시겠습니까?"` Confirm이 노출되며, 승인 시 `"강사 복직(재직 전환) 처리가 완료되었습니다."` Toast가 출력되는가?
- [ ] **삭제 제한 모달**:
  - 근태/스케줄 기록이 있는 강사를 삭제하려 할 때, 타이틀이 `"강사 정보 삭제 제한 안내"`로 표시되며 본문에 `"기록을 안전하게 보존하기 위해 삭제 대신 '퇴사 처리'로 관리해 주세요."` 및 8가지 세부 귀속 데이터 항목이 정상 표기되는가?
  - 모달 우측 하단의 버튼이 `"퇴사 처리하기"`로 자연스럽게 정렬되는가?
- [ ] **퇴사자 시각적 구분**:
  - 퇴사 상태 필터 조회 시, 목록 내 퇴사 강사의 이름 우측에 회색 `퇴사` 배지가 깔끔하게 부착되는가?

### 2) 강사 근태관리 화면
- [ ] **미퇴근 툴팁**:
  - 강사별 근무시간 요약 테이블의 '미퇴근 횟수' 헤더 옆 파란색 `i` 아이콘 호버 시 `"퇴근 기록이 누락된 근무는 총 근무시간 합산에서 제외됩니다."` 툴팁이 가림 현상 없이 자연스럽게 노출되는가?
- [ ] **모바일/좁은 화면**:
  - 모바일(가로 480px 이하) 뷰포트에서 `엑셀 다운로드`와 `근무 추가` 버튼이 텍스트 줄바꿈/잘림 없이 세로로 안전하게 스택되며 화면 너비에 맞게 균등 분할 배치되는가?
- [ ] **근무 추가/수정 모달**:
  - 근무 추가 모달의 타이틀이 `"근무 기록 추가"`이며 저장 시 Confirm 문구가 `"이 강사의 근무 기록을 새로 추가하시겠습니까?"`로 나오는가?
  - 근태 수정 모달의 타이틀이 `"근무 기록 수정"`이며 저장 시 Confirm 문구가 `"이 근무 기록을 수정하시겠습니까?"`로 나오는가?
  - 수정/추가 시 입력 placeholder 문구(`수정 사유 입력 (예: 태블릿 오작동 보정)`, `수동 추가 사유 입력 (예: 태블릿 체크 누락)`)가 사용자 친화적인가?

### 3) 시간표 및 스케줄 화면
- [ ] **퇴사 강사 시각 톤다운**:
  - 퇴사한 강사(예: `김민수 (퇴사)`)의 이름 배지 및 타임테이블 상단 헤더에 투명도(`opacity: 0.65`) 및 기울임꼴(`font-style: italic`) 스타일이 적용되어 재직 강사와 시각적으로 편안하게 구분되는가?
- [ ] **토글 필터**:
  - 스케줄 관리 상단의 체크박스 라벨이 `"퇴사한 강사 포함"`으로 자연스럽게 표시되며, 체크 해제 시 이력이 있는 퇴사 강사가 뷰에서 정상적으로 사라지는가?
- [ ] **일간 뷰 빈 상태 문구**:
  - 강사출근표 일간 뷰에 출근자가 없을 때 `"출근한 강사가 없습니다."` 문구가 표시되는가?
  - 강사-원생 시간표 일간 뷰에 필터 조건과 맞는 강사가 없을 때 `"일치하는 강사가 없습니다."` 문구가 중앙에 조화롭게 노출되는가?

### 4) 엑셀 다운로드
- [ ] **다운로드 작동 확인**:
  - `엑셀 다운로드` 버튼 클릭 시 브라우저 기본 다운로드가 시작되며 파일명이 `강사근태기록_YYYY-MM-DD_~.xls` 패턴으로 받아지는가?
- [ ] **엑셀 데이터 검수**:
  - Microsoft Excel 또는 Google Sheets에서 파일을 열었을 때 손상 경고 없이 정상 파싱되는가?
  - '월간 합산' 탭과 개별 강사 탭의 출퇴근 시간 계산 수치, 요약 통계(총 근무시간, 평균 근무시간 등)가 대시보드 화면상의 수치와 100% 일치하는가?
  - 기이한 이름(예: `강사 & <Test>`)을 가진 강사의 탭이 XML 파싱 에러 없이 이스케이프되어 온전하게 표시되는가?

## 3. 검수 방식 및 자동 테스트 커버리지

릴리즈 검수는 기 구축된 75개의 자동 E2E/단위 테스트와 운영자의 수동 확인으로 결합 수행됩니다.

### 1) 자동 테스트 커버 범위 (75개 테스트 완료)
* **근태 상태 전이**: 태블릿 PIN 패드 출퇴근 $\rightarrow$ 디렉터 대시보드 실시간 반영 및 KPI 카운트 검증.
* **근태 기록 수동 수정**: 시간 형식 밸리데이션(퇴근시각이 출근시각보다 이전일 때 차단) 및 수정 Confirm 확인, 수정 이력 테이블 자동 적재 검증.
* **강사 라이프사이클**: 강사 퇴사/복직 처리 동작, `active`/`resigned` 필터의 상태 토글, 삭제제한 밸리데이션(기록 보유자는 삭제 차단 및 경고 모달 노출).
* **엑셀 다운로드**: 다운로드 스트림 정상 캡처, 시트 생성 개수 정합성, XML 특수문자 Escape 및 시트명 Sanitize 검증.
* **버튼 레이아웃**: 데스크톱 및 모바일 뷰포트에서 두 버튼의 Bounding Box가 겹치지 않고 온전히 노출되는지 검증.

### 2) 수동 확인 필수 항목 (릴리즈 전 최종 눈 검수)
* **모바일 실기기 UI 터치**: 모바일 환경에서 달력 드로어의 터치 드래그 및 버튼 클릭 반응 속도.
* **실제 엑셀 소프트웨어 호환성**: 다운로드된 `.xls` 파일을 Microsoft Excel 정식 버전 및 Google Sheets에서 열 때 폰트 깨짐이나 셀 레이아웃 깨짐이 없는지 최종 뷰포트 확인.
* **모달 팝업 가독성**: 다이얼로그 팝업이 띄워졌을 때 배경의 스크롤이 잠기는지 및 모달 내 경고 텍스트의 가독성이 만족스러운지 검수.

## 4. 정책 요약 정리

| 구분 | 재직 강사 (`active`) | 퇴사 강사 (`resigned`) |
| :--- | :--- | :--- |
| **개념** | 현재 학원에서 수업을 배정받고 정상 출근하는 강사 | 학원을 퇴직하여 신규 조작에서 배제되는 강사 |
| **과거 기록** | 과거 모든 출결/시간표 기록 정상 조회 | 과거 축적된 출결/시간표에 강사 실명 및 이력 100% 보존 |
| **현재 운영** | 태블릿 출근 체크 리스트 노출, 수동 근무 추가 가능 | 신규 수강생 배정, 스케줄 입력, 주요 일정 담당자 등 활성 선택지에서 자동 제외 |
| **미래 배정** | 미래 주간 시간표 스냅샷 및 배정 목록 포함 | 스냅샷 생성 시 자동 배제 (조회 시 `퇴사한 강사 포함` 옵션 필수) |
| **삭제 가능 여부** | 연동된 과거 기록이 전혀 없는 신규/오등록 강사만 가능 | 물리 삭제 절대 불가 (삭제 시 제한 모달로 강제 퇴사 처리 유도) |
| **복직 정책** | N/A (이미 재직 상태) | 복직 시 기존 고유 ID 보존, 모든 과거 이력 및 연동 데이터 즉시 자동 원복 |

## 5. 리스크 및 향후 백로그 (Risks & Backlogs)

운영 시 주의해야 하거나 추후 개선이 제안되는 항목입니다.

1. **주요 일정 담당자 연동의 한글명 참조 취약성 (리스크)**
   - **현상**: 학원 주요 일정(`majorSchedules`) 내 담당자 식별이 `teacherId`가 아닌 강사의 한글 실명(`ownerId`) 문자열로 연동되어 있습니다.
   - **리스크**: 만약 동명이인이 존재하거나 강사의 한글 이름을 수정할 경우, 삭제 제한 검증 로직 및 과거 이력 매핑이 오동작할 위험이 있습니다.
   - **대책 (백로그)**: 차기 페이즈에서 `majorSchedules.ownerId`를 고유 식별자(`teacherId`) 기반 구조로 정규화하는 데이터 마이그레이션이 필요합니다.
2. **복직 이력 관리 부재 (백로그)**
   - **현상**: 현재는 퇴사와 복직 전환 시 `teacher.updatedAt` 타임스탬프만 변경되며, "언제 퇴사했다가 언제 복직했는지"에 대한 타임라인 히스토리(Audit Log)를 남기지 않습니다.
   - **리스크**: 한 강사가 반복적으로 퇴사/복직 처리가 될 경우 정확한 연혁 파악이 어렵습니다.
   - **대책 (백로그)**: 강사 정보 변경 이력을 기록하는 로그 테이블 설계가 백로그로 제안됩니다.
3. **엑셀 다운로드 `.xls` 경고 메시지**
   - **현상**: 브라우저 다운로드 방식에 가벼운 SpreadsheetML XML 템플릿(확장자 `.xls`) 형식을 채택하고 있습니다.
   - **운영 팁**: 엑셀 구버전 등 일부 환경에서 열 때 "파일 형식이 확장명과 일치하지 않습니다"라는 가벼운 경고 창이 뜰 수 있으나, "예"를 누르면 완벽하게 열립니다. 원장/사용자에게 사전 Q&A 가이드로 제공하는 편이 좋습니다.
