DayDay Planning Document

강사 시간표 운영 고도화 기획서

원장 권한의 강사 시간표 관리, 강사 출근표, 강사-원생 일간/주간 시간표, 특이사항, 출력/이미지 복사 기능을 실제 음악학원 운영 방식에 맞춰 정리한 개발 전 검토 문서입니다.

요약 판단

요구사항은 타당합니다. 다만 단일 기능이 아니라 “시간표 설정 + 출근표 + 수업표 + 특이사항 + 인쇄/공유”가 묶인 운영 보드입니다.

우선순위 높음

학원별 운영 시간/요일 설정과 일간 시간표는 실제 현장에서 바로 체감되는 기능입니다. 지금 붙이면 사용성이 크게 올라갑니다.

설계 주의

강사 출근표와 강사-원생 시간표는 비슷해 보이지만 데이터 목적이 다릅니다. 하나로 섞으면 이후 수정이 어려워집니다.

개발 전략

먼저 “표 설정”과 “일간 보기”를 만들고, 그 다음 인쇄/이미지 복사와 특이사항 포함 옵션을 붙이는 순서가 안전합니다.

이번 요구사항의 핵심

학원 운영시간 설정 강사 출근표 일간/주간 강사-원생 시간표 일간/주간 특이사항 노출 프린트 이미지 복사 테스트 자동화 필요

사용자 확정 운영 규칙

강사 출근표의 목적

강사들은 주간/월간 기본 시간이 있더라도 파트타임 특성상 실제 시간이 자주 바뀝니다. 이 화면은 원장이 실제 출근 상황을 확인하고, 필요하면 강사에게 출근표를 출력해 전달하기 위한 운영 기능입니다.

강사-원생 시간표의 목적

강사별로 어느 시간에 어떤 원생을 교육해야 하는지 확실히 잡아주는 기능입니다. 상황에 따라 강사에게 주간 교육 원생표 또는 일간 교육 원생표를 출력해 전달할 수 있어야 합니다.

과거/오늘/미래 시간표 규칙

과거 날짜와 오늘 운영표는 당시 기록된 이력을 기준으로 봅니다. 누군가 원생 시간을 옮겼다면 그 날짜의 운영표에는 옮긴 채로 고정됩니다. 단, 내일이 된 오늘이나 다음주차가 된 다음주의 시간표는 원생 기본값을 다시 반영합니다.

프린트 범위

프린트는 단순 예시 화면 하나를 출력하는 기능이 아니라, 사용자가 필터링한 일간/주간, 강사, 날짜, 특이사항 포함 여부를 그대로 반영해야 합니다.

이상하거나 확인이 필요한 지점

요구 자체는 자연스럽지만 개발 전에 용어와 저장 범위를 확정해야 합니다.

항목노티스권장 결정
강사 출근표 vs 강사-원생 시간표 둘 다 “강사별 시간표”처럼 보이지만 출근표는 강사의 근무 가능/출근 시간, 강사-원생 시간표는 실제 수업 배정입니다. 화면 탭은 분리하되 공통 표 엔진을 공유합니다.
일간 시간표의 날짜 선택 과거 날짜 확인은 당시 기록된 이력 기준입니다. 오늘 운영표도 현재 기록된 이력 기준입니다. 원생 시간이 이동되면 해당 날짜 운영표는 이동된 상태로 고정됩니다. 미래 날짜는 원생 기본 시간표를 기준으로 생성합니다. 기본값 자체를 바꾸고 싶으면 원생 정보의 기본 시간표를 수정합니다.
드래그로 일시 변동 드래그로 옮긴 변경은 해당 날짜의 운영 이력으로 저장되어야 합니다. 과거/오늘 화면에서는 옮긴 상태가 고정되어 다시 보여야 합니다. 다만 미래의 반복 시간표는 원생 기본 시간표에서 다시 생성됩니다. 반복 기본값 변경은 반드시 원생 기본 시간표 수정에서 처리합니다.
특이사항 출력 포함 특이사항에는 개인정보/민감정보가 들어갈 수 있습니다. 출력/이미지 복사 시 포함 여부가 꼭 필요합니다. 기본값은 미포함, 원장이 토글로 포함합니다. 포함 시 화면에 표시가 필요합니다.
이미지화하여 복사 브라우저에서 DOM을 이미지로 복사하려면 html2canvas류 라이브러리 또는 별도 Canvas/SVG 렌더러가 필요할 수 있습니다. 1차는 인쇄 CSS와 PNG 다운로드, 2차로 클립보드 복사를 붙입니다.
프린트 1/2/3개 배치 가능합니다. 다만 A4 가로/세로, 여백, 글자 크기, remarks 포함 여부에 따라 가독성이 크게 달라집니다. A4 가로 기준 1개/2개/3개 레이아웃 프리셋을 제공합니다.

1. 학원별 테이블 설정

월~금, 15:00~20:00처럼 학원 운영 방식에 맞게 시간표 테이블 자체를 줄이는 기능입니다.

필요 설정값

기본 운영 시간
  • 운영 요일: 월, 화, 수, 목, 금, 토, 일 중 선택
  • 시작 시간: 예 14:00 또는 15:00
  • 종료 시간: 예 20:00 또는 21:30
  • 시간 간격: 10분, 15분, 30분, 60분
  • 점심/휴게/비노출 구간: 선택 기능 후보
표 표시 옵션
  • 빈 시간대 숨김 여부
  • 강사별 컬럼 폭 자동/고정
  • 모바일에서는 가로 스크롤 또는 강사별 접기
  • 인쇄용 글자 크기 프리셋
  • remarks 영역 우측/하단 위치 선택

데이터 후보

필드설명예시
scheduleDays시간표에 노출할 요일["mon", "tue", "wed", "thu", "fri"]
scheduleStartTime첫 노출 시간15:00
scheduleEndTime마지막 노출 시간20:00
scheduleSlotMinutes칸 간격30
printLayoutDefault기본 출력 배치one-per-page, two-per-page, three-per-page

2. 강사 출근표 관리

파트타임 강사의 실제 출근 변동을 원장이 확인하고, 필요 시 강사에게 출력해 전달하기 위한 운영표입니다.

주간 보기

  • 강사 1명을 선택하면 해당 강사의 월~일 출근 타임테이블 표시
  • 출력/이미지 복사 가능
  • 강사에게 본인 주간 스케줄을 보내기 좋게 구성
  • 강사 특이사항 포함 여부 토글

일간 보기

  • 날짜 단일 선택
  • 선택 날짜에 출근하는 강사만 컬럼으로 노출
  • 필터: 강사명, 담당 과목, 출근 여부, 상태
  • 우측 또는 하단에 선택 강사 특이사항 표시

강사 특이사항

강사 등록/수정 화면에 staffNotes 또는 scheduleNotes 필드를 추가합니다. 모바일에서는 테이블 칸에 직접 다 넣기보다 “특이사항” 버튼을 눌러 모달로 보는 방식이 더 안정적입니다.

개인정보 주의

강사 특이사항에는 급여, 개인 사정, 근태 민감 정보가 들어갈 수 있습니다. 출력/복사 시 포함 토글은 반드시 필요합니다.

3. 강사-원생 시간표 관리

강사별로 어떤 시간에 어떤 원생을 교육해야 하는지 확정해 보여주는 수업 운영표입니다. 과거/오늘은 기록된 이력, 미래는 원생 기본값을 기준으로 합니다.

보기동작주의점
주간 보기 현재와 같이 원생별 기본 시간표를 요일/시간 기준으로 노출합니다. 기존 기능을 최대한 유지합니다.
일간 보기 선택 날짜의 출근 강사를 열 제목으로 두고, 각 시간대에 담당 원생을 배치합니다. 오늘 출근하는 강사의 수업 현황을 한눈에 보는 운영판입니다.
드래그 임시 변동 원생을 다른 시간/강사 칸으로 드래그하면 해당 날짜의 운영 이력에 저장됩니다. 그 날짜를 다시 열면 이동된 상태로 보여야 합니다. 하지만 다음날/다음주 기본 생성에는 원생 기본 시간표가 다시 적용됩니다.
원생 특이사항 원생 등록/수정 테이블에 “시간표 등 일정 특이사항” 입력란을 추가하고, 시간표 우측/하단에 노출합니다. 출력/이미지 복사에 포함 여부 토글을 둡니다.

4. 인쇄 및 이미지 복사 기능

첨부 이미지처럼 하루 운영표를 종이 또는 이미지로 공유하는 기능입니다.

가능 여부

프린트

가능합니다. CSS @media print와 레이아웃 프리셋으로 구현합니다.

PNG 다운로드

가능합니다. DOM 캡처 라이브러리나 Canvas 렌더러가 필요할 수 있습니다.

이미지 복사

가능하지만 브라우저 권한/호환성 이슈가 있어 다운로드를 1차, 클립보드 복사를 2차로 권장합니다.

프린트 옵션

  • 현재 필터링된 일간/주간, 날짜, 강사 조건을 그대로 반영
  • 한 페이지에 표 1개, 2개, 3개 배치 선택
  • A4 가로 기본, A4 세로 후보
  • 강사 특이사항 포함/미포함
  • 원생 특이사항 포함/미포함
  • 빈 시간대 숨김/표시
  • 폰트 크기: 작게, 보통, 크게

5. 구현 우선순위

한 번에 다 만들면 위험합니다. 표 설정부터 시작해 일간 운영표와 출력 기능을 단계적으로 붙이는 편이 안전합니다.

  1. 시간표 테이블 설정 완료 (Phase 7A)
    운영 요일, 시작/종료 시간, 칸 간격, 인쇄 기본값을 학원 설정에 추가합니다.
  2. 강사/원생 특이사항 필드 추가 완료 (Phase 7A)
    강사 관리에는 강사 특이사항, 원생 관리에는 시간표 등 일정 특이사항을 추가합니다.
  3. 강사 출근표 일간/주간 보기 완료 (Phase 7B)
    강사의 실제 출근 변동 이력을 확인하고, 선택한 날짜/강사/주간 조건 그대로 출력할 수 있게 만듭니다.
  4. 강사-원생 일간/주간 시간표 완료 (Phase 7C)
    강사별 교육 원생표를 구현하고, 필터/날짜 선택/특이사항 토글 기반을 다집니다.
  5. 주간 보기 개선
    강사 1명의 주간 출근표와 기존 강사-원생 주간표를 정리합니다.
  6. 프린트/이미지 내보내기
    사용자가 필터링한 일간/주간/강사 조건과 특이사항 포함 토글을 반영해 한 페이지 1/2/3개 배치, PNG 다운로드, 클립보드 복사를 순서대로 붙입니다.
  7. E2E 테스트 확장 완료 (Phase 7C)
    표 설정 저장, 일간 보기 날짜 선택, 수납/출결처럼 새 기능별 자동 테스트를 추가합니다.

6. 테스트 계획

현재 프로젝트는 테스트 기반이 생겼으므로, 기능 구현과 동시에 E2E를 붙여야 합니다.

기능자동 테스트 기준우선순위
표 설정 저장운영 시간 15:00~20:00 설정 후 시간표 행이 해당 범위만 렌더링되는지 확인상
강사 특이사항강사 등록/수정 후 일간 출근표의 특이사항 패널에 노출되는지 확인상
