## 2. 완료된 범위 (Phase 8C 완료 목록)

* **[x] A. 시간 선택 UX 보정**
  * 오전/오후 - 시간 - 분 순서의 커스텀 셀렉트 UI 제공.
  * 분 선택은 **5분 단위**로 제한하여 터치/마우스 빠른 입력 지원.
  * 시작시간 변경 시 종료시간 자동 연동 (+1시간) 및 사용자 수동 변경 후 덮어쓰기 방지 예외 처리 적용.
* **[x] B. 운영대기업무 시간순 정렬 정책**
  * `startAt` / `dueAt` / `createdAt` 우선순위에 따른 통합 대기 업무 시간순 정렬 정책 수립 및 큐 렌더링 반영.
* **[x] C. 완료 업무 보존 표시**
  * 완료(done) 처리 시 화면에서 즉각 제거하지 않고, 취소선(`line-through`) 및 55% 불투명도(`opacity: 0.55`), 완료 배지를 입혀 오늘 하루 동안 큐와 캘린더 칩에 보존 및 회고 지원.
* **[x] D. 운영대기업무 + 캘린더 병렬 레이아웃**
  * 좌측: 운영대기업무 큐 (Active & Completed Queue)
  * 우측: 일간/월간 캘린더 타임라인 병렬 오버레이 구성.
* **[x] E. App Calendar / mockCalendarEvents**
  * `mockCalendarEvents`와 `TodayTask` (일정 설정 완료 건) 데이터를 병합하여 캘린더 그리드에 통합 렌더링.
* **[x] 추천확인 Provider 및 UI 연결**
  * 당월 수강료 미납 및 오늘 출결 입력 지연 추천 룰을 탑재한 `syncSystemRecommendations` 엔진 연동.
  * UI에 보라색 **[추천확인]** 뱃지 및 캘린더 보라색 칩 매핑 완료. 리렌더링 시 무한 업데이트 루프 차단용 `isChanged` 판별 가드 적용.
* **[x] 수동 QA용 Opt-in 데모 데이터 seeder**
  * 쿼리스트링 `?demoRecommendations=1` 및 localStorage 플래그에 기반한 수동 검증용 데모 seeder 및 헤더 보라색 플라스크 뱃지 연동 완료. (E2E 테스트 환경 격리)

## 3. Google Calendar 연동 스킵 결정
* **[Deferred] F. Google Calendar 실제 연동**
  * 실제 Google OAuth 및 API 직접 연동은 **로드맵에서 Deferred(보류/스킵) 처리**되었습니다.
  * 단, `stateStore` 내부의 Provider 모듈형 인터페이스 설계는 그대로 유지하여, 향후 비즈니스 요건 변화나 타 세그먼트 확장 시 즉각 구현이 가능하도록 아키텍처적 유연성을 남겨둡니다.

## 4. 남은 백로그 및 우선순위 후보

### G. 구분 (Category) 관리 고도화
* **내용**: MVP 기본 구분(메모, 상담예약, 확인필요, 추천확인) 외에 원장이 직접 설정 화면에서 업무 카테고리를 추가/수정/삭제할 수 있는 CRUD 지원.
* **영역**: Segment Config 또는 사용자 settings 데이터 모델 추가.

### H. 원장 콘솔 전체 UX 고도화 (Delight Loop & 관제)
* **내용**: 단순한 TODO 리스트를 넘어 수납, 출결, 교재, 이탈 위험 등의 리스크/Delight 시나리오가 콘솔 카드 내 액션 버튼(예: `[독촉장 발송]`, `[칭찬 알림 발송]`)과 클릭 한 번으로 실행되도록 비즈니스 흐름을 연결.

### I. 입력 폼 UX 미세 개선 및 실사용성 QA
* **내용**: 모바일 뷰포트 레이아웃 최적화, 시간 선택 시 키보드 터치 다이얼로그 팝업 개선, 메모 카드 클릭 시 인라인 수정 및 세부 팝업 기능 보강.
