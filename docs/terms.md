# DayDay 용어 사전 (Terminology Dictionary)

본 문서는 DayDay 서비스의 UI 및 내부 데이터 모델 간 용어 통일성을 기하고, 향후 다중 업종 확장 시 공통적으로 재사용할 수 있는 용어 정의 및 설계 원칙을 정리합니다.

---

## 1. 핵심 용어 정의 (Core Terminology Mappings)

출시 전 신뢰도를 높이기 위해, 음악학원 MVP 화면에 노출되는 UI 텍스트와 내부 데이터 필드를 아래 표준에 맞추어 통일합니다.

| 내부 시스템 명칭 (code) | 권장 한국어 명칭 (UI) | 음악학원 전용 용어 | 타 업종(예: 피트니스, 레슨) 변환 명칭 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `Student` / `Member` | **원생** | 원생 | 회원 / 수강생 | 학원에 등록하여 수업을 듣는 핵심 고객 |
| `Parent` | **학부모** | 학부모 | 보호자 / 결제자 | 원생의 보호자 및 청구서 수신/결제 대상자 |
| `Teacher` / `Staff` | **강사** | 강사 | 트레이너 / 교사 | 수업을 담당하고 일지를 작성하는 교육 공급자 |
| `Class` / `Lesson` | **수업** (또는 **레슨**) | 수업 / 레슨 | 세션 / 클래스 | 강사와 원생이 만나 교습을 진행하는 단위 시간 |
| `Payment Status: paid` | **수납 완료** | 수납 완료 | 결제 완료 / 납부 완료 | 청구된 수강료가 원장실/학부모 포털을 통해 납부된 상태 |
| `Payment Status: unpaid`| **미납** | 미납 | 미납 / 미결제 | 수강료 청구서가 발행되었으나 아직 납부되지 않은 상태 |
| `Attendance` | **출결** | 출결 | 입장 / 출석 | 수업 참석 여부 기록 (등원, 하원, 결석, 보강 등) |
| `Make-up Class` | **보강** | 보강 수업 / 보강 | 보강 세션 / 대체 수업 | 결석한 정규 수업을 대체하여 진행하는 보충 수업 |
| `Lesson Journal` | **수업일지** | 수업일지 | 피드백 / 운동일지 | 수업 내용, 진도 및 강사의 개별 피드백 기록 |
| `Announcement` | **공지사항** | 공지사항 | 공지사항 / 알림 | 학원 전체 또는 특정 대상에게 전달하는 공식 알림 |
| `Message` | **개별 안내** | 개별 안내 | 개별 알림 | 특정 학부모/원생에게 개별적으로 보내는 메시지 |
| `Survey` | **설문** | 설문 | 만족도 조사 / 설문 | 피드백 수집 및 정보 확인을 위한 조사서 |

## 2. 다중 업종 확장 시 용어 분리 원칙 (Design Principles)

1.  **화면 표시 용어와 내부 데이터 모델의 분리**:
    *   내부 데이터베이스 모델(DB Schema)과 API 파라미터는 업종별 코딩의 파편화를 막기 위해 최대한 범용적이고 추상적인 영어 명칭을 사용합니다.
        *   *예시*: 화면에는 `"원생"` / `"강사"` / `"수납 완료"`로 표시되지만, 데이터베이스 구조는 `student` / `teacher` / `paymentStatus: 'paid'`로 유지합니다.
    *   향후 헬스장 버전을 론칭할 때는 프론트엔드 다국어/용어 사전 맵핑 레이어(Localization/Translation Layer)를 도입하여, 동일한 `student` 데이터를 화면 상에 `"회원"`으로 치환하여 렌더링합니다.
2.  **화면 내 용어 일관성 유지**:
    *   동일한 탭이나 한 화면 안에서 "학생"과 "원생", "결제"와 "수납"을 혼용하지 않습니다.
    *   *원장 화면*에서는 행정 관리 목적에 맞추어 **"원생 관리"**, **"수납 관리"** 등의 행정 용어를 사용합니다.
    *   *학부모 화면*에서는 친근한 용어인 **"자녀 정보"**, **"수업일지"**를 노출하여 신뢰감을 줍니다.

---

## 3. 화면별 표준 표기 점검 가이드 (Checklist)

*   **로그인 / 역할 선택 화면**: "학생 / 학부모 로그인" -> **"원생 / 학부모 로그인"**으로 수정하여 용어 통일.
*   **원장 대시보드 및 메뉴**: "수강생 대장 인쇄" -> **"원생 대장 인쇄"**로 수정. "unpaid" 상태 노출 필드는 **"미납"**으로 통일.
*   **강사 화면**: "레슨 피드백" 또는 "레슨일지" -> **"수업일지"**로 통일.
*   **학부모 안심 포털**: "레슨 피드" -> **"수업일지"**, "설문조사" -> **"설문"**, "개별 안내장" -> **"개별 안내"**로 표준화.
